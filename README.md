# Chemical Engineering Study Resource Hub (ChE Hub)

> **Live Web Application**: [https://che-resource-hub.pages.dev/](https://che-resource-hub.pages.dev/)  
> **Mirror Deployment**: [https://che-resource-hub.vercel.app/](https://che-resource-hub.vercel.app/)

A high-performance study resource and reference catalog for Chemical Engineering undergraduate students (BUET ChE). Includes textbooks, solution manuals, term-final question banks, lecture slides, and video archives.

---

## 📚 Resource Catalog

- **Core Reference Books**: Bird Stewart Lightfoot (*Transport Phenomena*), Fogler (*Chemical Reaction Engineering*), McCabe-Smith (*Unit Operations of Chemical Engineering*), Smith Van Ness (*Chemical Engineering Thermodynamics*), Coulson & Richardson, Perry's Chemical Engineers' Handbook.
- **Solution Manuals**: Step-by-step problem set solutions and worked derivations for major engineering textbooks.
- **Term-Final Question Bank**: Archived past-year university examination papers and worked solution keys.
- **Class Slides & Assets**: Lecture slide decks, formula sheets, and reference notes organized by Level (1 to 4) and Term (1 to 2).
- **Simulation Files**: Aspen HYSYS flowsheets, simulation backups (.hsc, .bk0), and MATLAB scripts.

---

## ⚡ Features

- **Sub-Second Instant Preview**: Generates fast initial page previews (<150 KB) so students can view documents within 1–2 seconds with zero canvas lag.
- **Direct Download**: High-speed native browser downloading with byte-range support.
- **Unified Academic Navigation**: Filter by Level/Term or search across all courses and assets instantly.
